# peer_chat

how to install and run


for linux use the following commands (bash): 

1) chmod +x install.sh
2) ./install.sh
3) source venv/bin/activate
4) python3 ./peer/full_peer.py # to run it


fow windows use the following commands (shell): 

1) install.bat
2) venv\Scripts\activate
3) python peer\full_peer.py # to run it
